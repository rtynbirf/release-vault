# AGENTS.md — инструкции для агентов клетки release-vault

Клетка живёт по законам роя (README.md ядра cell-swarm).

## Что это за клетка

Шифрованный офсайт-архив релизных ассетов приватных репозиториев `rtynbirf`
(волна «Зелёный Сингуляр», 07.11.2026): освобождение Actions-storage квоты.
Тела — зашифрованные ассеты в GitHub Releases; в дереве репозитория кода нет.

## Схема (факты, не нарратив)

- Шифрование: AES-256-CBC, PBKDF2-SHA1, 600 000 итераций (openssl enc).
- Имена нейтрализованы (`rXaYY.enc`); исходные имена/размеры/SHA256 — только
  внутри `__MANIFEST.enc` каждого релиза.
- `__SHA256SUMS.txt` — хеши шифротекстов: целостность проверяется БЕЗ ключей.

## Законы клетки

1. Ключи НИКОГДА не хранятся в этом репозитории и в его CI-секретах.
2. CI не расшифровывает: только сверяет хеши шифротекстов (vault-integrity).
3. Расшифровка — только офлайн, руками владельца, на своём железе.
4. Ассеты не удаляются и не перезаписываются: архив только-добавление.

## Порядок чтения

1. `README.md` — схема и назначение.
2. Releases — тела (`.enc` + `__SHA256SUMS.txt` + `__MANIFEST.enc`).
3. `.github/workflows/vault-integrity.yml` — машинная сверка целостности.
4. `.github/workflows/self-audit.yml` — еженедельный ПУЛЬС (гигиена/свежесть).
