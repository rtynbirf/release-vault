# Сертификат офлайн-копии №2 · «день пломбы» (ПРЕДЛОЖЕНИЕ-19, issue #1, W3-A2)

Канон 3-2-1-1-0: считаются только проверенные восстановления — ноль ошибок
при drill. Квартальный ритуал и журнал drill'ей живут в `wave3/ДЕНЬ-ПЛОМБЫ.md`
(волна ×3 W3-A); этот сертификат — датированное свидетельство КОПИИ №2
(критерий приёмки «копия №2 датирована»), которого в ритуале не было.

Правило пломбы: каждая физическая копия №2 заводит НОВЫЙ сертификат-файл
`СЕРТИФИКАТ-КОПИЯ-2-ГГГГ-КВ.md` (копия этого шаблона), прошлые сертификаты
не переписываются никогда — append-only цепочка свидетельств. Ошибочная
строка не стирается: рядом пишется корректирующая.
